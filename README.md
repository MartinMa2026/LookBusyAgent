## 🏄‍♂️ 如何开始带薪摸鱼？

### 步骤 1：获取装备
作为最懂你的摸鱼工具，我们提供可以直接运行的“单体纯净版”。前往 `dist/` 目录双击运行 `LookBusyAgent.exe`，或者源码运行：
```bash
pip install -r requirements.txt
python main.py
```

### 步骤 2：启动欺诈仪式
1. 告诉 AI “你是谁 / 在做啥”（没想好就不填）。
2. 勾选需要被操作的软件（比如微信、网页、代码 IDE、Excel表格）。
3. 随时填入自己喜欢的 LLM API Key（不填就用降级的内建废话模板）。
4. 在顶部选择所需的当地语言，点击右下角「🚀 START FISHING」。
5. **双手离开键盘，开始放心刷手机。**

### 🔌 极简的 1 分钟接入方案：
你**不需要**修改现有的任何主线控制逻辑或路由表，架构会在启动时自动将你的脚本反射注册并塞入前端面板！只需两步：

1. 新建 `adapters/your_app_name.py`
2. 继承基类并贴上你的专属 `META` 属性名牌：

```python
from adapters.base_adapter import BaseAdapter

class WhatsAppAdapter(BaseAdapter):
    # 只要有了这个 META 标签，程序就会自动发现并接入它！
    META = {
        "names": ["WhatsApp"],                  # UI显示的别名
        "processes": ["whatsapp.exe"],          # 监听的系统进程
        "icon": "💬",                           # UI展示的 emoji 
        "priority": 1                           # 权重
    }
    
    def run_action(self):
        # 开始编写你想要的鼠标滑行逻辑 / 键盘盲打逻辑吧！
        pass
```

编写完毕后，无需改动任何系统文件，你可以直接提 PR！或通过一行打包命令生成最终执行体：
```bash
pyinstaller --noconfirm --onefile --windowed --icon "assets/icon.ico" --add-data "config;config" --add-data "assets;assets" --collect-submodules adapters main.py -n LookBusyAgent
```
