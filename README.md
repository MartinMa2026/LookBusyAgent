# Look-Busy Agent 🎭
**反内卷利器 · 你的首席“伪装工作”官**

**Look-Busy Agent**
是个开源、免费、绿色免安装的Windows小工具。它不需要你写一串复杂的代码，就能接管你的屏幕，用像素级的真实鼠标微操、随性的键盘敲击，以及一本正经胡说八道的“AI 废话生成器”，帮你维持一个**“全公司最卷、最忙、最不可替代”**的敬业人设。😎

---

## 🔥 核心功能

- **⏱️ 摸鱼倒流计费器**：每秒精准统计你今天偷偷赚回了多少青春。帮你记录“反吸血”收益。
- **👀 瞒天过海的真人操作**：鼠标移动采用了讲究的贝塞尔曲线（不是那种一眼假的机械平移），还会随机发呆、点击、偶尔来回翻滚网页，完美还原人类“边思考边发呆”的边缘状态。
- **🤖 高端废话生成器**：只要你输入自己的岗位和今天要做什么，接上 AI 大脑后，它会在你的 Word 或代码编辑器里疯狂敲击出诸如“赋能、架构、闭环”的高深段落，然后边打边立刻删，主打一个“我很纠结、我在深度修改”。
- **💨 纯净无痛，随时待命**：如果你不懂 Python，直接去 `dist/` 下载单体 `.exe`，双击就能跑，无任何流氓弹窗和多余残留。
- **🌍 打工人跨国共识**：自带 中/英/日 语言一键热切。摸鱼的需求是没有国界的！
- **🚨 救命老板键 (F12)**：遇到突发情况一键拍下 `F12`，屏幕立刻切回给你自己。

## 🏄‍♂️ 怎么开启？

### 步骤 1：领装备
不想折腾环境的话，直接去 `dist/` 目录双击运行 `LookBusyAgent.exe` 就行。
当然，喜欢看源码的大佬可以这样跑：
```bash
pip install -r requirements.txt
python main.py
```

### 步骤 2：启动欺诈仪式
1. 告诉面板“你是谁 / 在做啥”（没想好的话不填也行）。
2. 在列表里勾选你平时常用的软件（网页、IDE、Word 都可以）。
3. 填入你自己的 LLM API Key（如果嫌麻烦不填，它也会用内置的弱智降级废话模板撑场面）。
4. 点击右下角闪烁的「▶ START FISHING」。
5. **现在，你可以放开双手，安心去刷手机、喝咖啡了。**

### 🔌 1 分钟就能写完的接入规则：
你**不需要**修改现有的任何控制逻辑，引擎会自动靠反射把你的脚本加载进 UI 里，只需两步：

1. 在 `adapters/` 目录下新建个脚本，比如 `your_app_name.py`。
2. 继承基类，画好你的专属 `META` 属性名牌：

```python
from adapters.base_adapter import BaseAdapter

class WhatsAppAdapter(BaseAdapter):
    # 填好这个名牌，程序启动时就会自动把它加进面板！
    META = {
        "names": ["WhatsApp"],                  # UI 上显示的别名
        "processes": ["whatsapp.exe"],          # 要挂钩监听的系统进程名
        "icon": "💬",                           # 随便配个顺眼的 emoji
        "priority": 1                           # 权重
    }
    
    def run_action(self):
        # 在这里写你希望鼠标和键盘在这个软件里做的各种“花里胡哨”的动作吧！
        pass
```

### 📦 怎么打包发行版？
如果你自己改了代码并想打包扔给同事，千万别去死磕复杂的 PyInstaller 参数和环境坑（比如 Anaconda 动不动丢 DLL 的老毛病）。
我们提供了一个自动修补依赖防坑的构建脚本，你只需要在控制台敲这句：
```bash
python build.py
```
喝口水，崭新打包好的 `LookBusyAgent.exe` 就会老老实实呆在 `dist/` 目录里了。
